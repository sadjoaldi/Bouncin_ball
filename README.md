1-  Clonez ou téléchargez ce dépôt sur votre machine.

2 - Assurez-vous d'avoir les fichiers suivants dans votre répertoire de projet :
- index.html
- style.css
- script.ts

3 - Pour compiler le code TypeScript en JavaScript :
- Installez TypeScript si vous ne l'avez pas encore fait

4 - Compilez le fichier TypeScript en utilisant la commande suivante dans votre terminal :
- tsc script.ts

- Cela générera un fichier script.js que vous pouvez inclure dans votre HTML.

5 - Pour une exécution automatique de TypeScript à chaque modification, vous pouvez utiliser la commande suivante :
- tsc --watch script.ts
